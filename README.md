# Сахалинский центр искусственного интеллекта

Одностраничный сайт без сборки и серверных зависимостей. Содержание и интерактивные диаграммы сохранены из предоставленной страницы; дизайн, навигация и медиа адаптированы для публикации.

## Локальный запуск

Из каталога репозитория:

```sh
python3 -m http.server 8080 --bind 0.0.0.0
```

Откройте страницу через локальный сервер. Проверяйте настольную и мобильную ширину, ссылки разделов, смену темы, увеличение изображений и воспроизведение видео. Шрифты загружаются с CDN jsDelivr; при отсутствии сети используется системный шрифт.

## Медиа

Изображения находятся в `media/`. Видео `segment.mp4`, `road.mp4` и дополнительное `b-boxes.mp4` хранятся локально и исключены из Git из-за размера. При переносе на VPS нужно скопировать весь каталог `media` отдельно, включая видео. Исходные материалы: https://drive.google.com/drive/folders/14706gY7NSIbK1nckdvYxPaqamwaajcGW

## Размещение на VPS

Подойдёт обычный статический сервер Nginx или Caddy. Загрузите `index.html`, `design.css`, `site.js` и каталог `media` в корень сайта. Node.js и база данных не требуются. Настройка домена и HTTPS выполняется после уточнения ОС сервера и доменного имени. Эта версия сама ничего не публикует.
